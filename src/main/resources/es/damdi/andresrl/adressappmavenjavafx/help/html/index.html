🔄 Gestión de Contactos

Crear Nuevo Contacto

Para agregar un nuevo contacto:

  1. Haz clic en Archivo → Nuevo
  2. Completa todos los campos obligatorios
  3. Presiona Guardar

Editar/Eliminar Contactos

Selecciona un contacto de la tabla y:

  • Doble clic para editar
  • Botón derecho → Eliminar

💾 Persistencia de Datos

La aplicación usa JSON para guardar los datos:

// Ejemplo de guardado
Archivo → Guardar (Ctrl+S)
// Formato JSON generado:
{
  "persons": [ ... ]
}

⌨️ Atajos de Teclado

Combinación Acción Menú
Ctrl + N Nueva Agenda Archivo → Nuevo
Ctrl + O Abrir Archivo Archivo → Abrir
Ctrl + S Guardar Archivo → Guardar
Ctrl + Q Salir Archivo → Salir
